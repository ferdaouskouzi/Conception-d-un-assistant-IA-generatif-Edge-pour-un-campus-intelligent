Comment fonctionne FERHAA
1. Vous posez une question
Votre message est d'abord analysé par le filtre RGPD local — aucune donnée personnelle (CIN, email, téléphone) ne doit être transmise.
2. Vérification du cache local
Si la question a déjà été posée, la réponse est renvoyée instantanément depuis la base locale (cache.db) sans appel réseau.
3. Appel à l'IA Groq Cloud
La question et un contexte académique (filière, année) sont envoyés au modèle Llama 3 8B via l'API Groq. Aucune donnée nominative n'est incluse.
4. Mode dégradé (si Groq indisponible)
FERHAA bascule automatiquement sur un modèle local via Ollama — la réponse reste disponible, même hors connexion.
5. Journalisation locale
Chaque échange est enregistré dans donnees_locales.db sur votre machine uniquement (question, réponse, source, durée).

Vos droits (RGPD)
Droit Description Comment l'exercer
📋 Accès Consulter toutes vos données stockées. Page Historique ou demande à l'admin.
