Important :

Pour lancer l'application depuis le projet :
1. Ouvrir un terminal dans c:\Users\LENOVO\mon_projet
2. Executer : python backend\app.py
3. Ouvrir : http://127.0.0.1:5000

Fichiers export utiles :
- export_flask\templates : copie des pages HTML
- export_flask\run_export.bat : lance l'application Flask existante
